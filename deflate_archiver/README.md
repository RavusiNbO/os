# Deflate Archiver

Простая реализация архиватора и разархиватора с использованием алгоритма deflate (LZ77 + Huffman) на языке C.

## Компиляция

```bash
make
```

## Использование

### Создание архива

```bash
./deflate_archiver -c <директория> <архив>
```

Пример:
```bash
./deflate_archiver -c ./test_dir archive.dfl
```

### Распаковка архива

```bash
./deflate_archiver -x <архив> <выходная_директория>
```

Пример:
```bash
./deflate_archiver -x archive.dfl ./extracted
```

## Алгоритм

Архиватор использует:
1. **LZ77** - алгоритм сжатия, который находит повторяющиеся последовательности
2. **Huffman coding** - кодирование с переменной длиной кода на основе частоты символов
3. **Canonical Huffman codes** - канонические коды для более эффективного хранения

## Структура архива

- Количество файлов (size_t)
- Для каждого файла:
  - Длина пути (uint16_t)
  - Путь (char[])
  - Тип: директория или файл (bool)
  - Размер сжатых данных (size_t)
  - Сжатые данные (uint8_t[])

## Очистка

```bash
make clean
```
